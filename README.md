# Skoleeventyret

**[Spill i nettleseren](https://perkap1.github.io/skoleeventyret/)**

Et pikselspill med tre utfordringer: klasseromskamp på 60 sekunder, overlevelse på Kon-Tiki og en langgang med levende blyanter og skolesekker.

Spill på PC med tastatur:

| Tast | Handling |
| --- | --- |
| WASD / piltaster | Bevegelse |
| E / Enter | Gå gjennom en dør |
| J / venstre museknapp | Lett angrep og tre slags kombo |
| K / høyre museknapp | Tungt angrep |
| Mellomrom | Unnvikelse |
| J / mellomrom gjentatte ganger | Dra sekken av hodet |
| Esc | Pause |
| H i pause eller resultat | Tilbake til startgangen |
| M | Lyd av/på |

Klikk i spillet for å aktivere tastatur og lyd. Poengrekorder lagres lokalt i nettleseren.

Dette prosjektet inneholder den ferdige nettversjonen. Redigerbare Godot- og Aseprite-filer oppbevares separat og privat.

Spillmotor: Godot 4.4.1. Motorens lisenser følger med i nettspillpakken.
